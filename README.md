# 📄 Proyecto: Mi CV en HTML

## 📋 Descripción del Proyecto

En este proyecto deberás crear tu **Currículum Vitae (CV)** en formato HTML, aplicando los conocimientos básicos de desarrollo web que hemos aprendido en clase.

## 🎯 Objetivo

Crear una página web que funcione como tu CV personal, mostrando tu información profesional de manera atractiva y organizada.

## 📝 Requisitos del Proyecto

### 1. Nombre del Archivo
Tu archivo **DEBE** llamarse:
```
CVNombreApellido.html
```

**Ejemplos:**
- `CVJuanPerez.html`
- `CVMariaGomez.html`
- `CVCarlosRodriguez.html`

### 2. Contenido Mínimo Requerido

Tu CV debe incluir **al menos** las siguientes secciones:

- ✅ **Información Personal**
  - Nombre completo
  - Profesión u ocupación
  - Información de contacto (email, teléfono, ubicación)

- ✅ **Sobre Mí**
  - Breve descripción personal y profesional (2-3 párrafos)

- ✅ **Educación**
  - Estudios realizados o en curso
  - Institución educativa
  - Fechas

- ✅ **Experiencia** (si aplica)
  - Trabajos realizados
  - Descripción de responsabilidades
  - O proyectos personales/escolares

- ✅ **Habilidades**
  - Habilidades técnicas
  - Herramientas que conoces
  - Idiomas

### 3. Tecnologías a Utilizar

#### Obligatorio:
- **HTML5** - Estructura de tu página

#### Opcional (pero recomendado):
- **CSS** - Para darle estilo y diseño a tu CV
  - Puedes usar CSS en la etiqueta `<style>` dentro del HTML
  - O crear un archivo `styles.css` separado

## 🎨 Aspectos de Diseño

### Recomendaciones:
- Usa una estructura clara y organizada
- Aplica colores que se vean profesionales
- Asegúrate de que el texto sea legible
- Usa espaciados adecuados entre secciones
- Si usas CSS, experimenta con:
  - Colores y fondos
  - Fuentes diferentes
  - Bordes y sombras
  - Diseño responsivo (que se vea bien en móvil)

### Etiquetas HTML sugeridas:
```html
<header>    - Para el encabezado con tu nombre
<section>   - Para cada sección del CV
<h1>, <h2>  - Para títulos y subtítulos
<p>         - Para párrafos de texto
<ul>, <li>  - Para listas de habilidades o experiencias
<a>         - Para enlaces (email, redes sociales)
<div>       - Para agrupar contenido
```

## 📤 Entrega del Proyecto

### Pasos para entregar:

1. **Crea tu archivo** `CVNombreApellido.html`

2. **Sube tu proyecto a GitHub**:
   - Crea un repositorio nuevo (puede llamarse "mi-cv" o "cv-proyecto")
   - Sube tu archivo HTML (y CSS si lo creaste por separado)
   - Asegúrate de que el archivo se llame correctamente

3. **Activa GitHub Pages** (opcional pero recomendado):
   - Ve a Settings → Pages
   - Selecciona la rama "main"
   - Tu CV estará disponible en línea

4. **Comparte el enlace**:
   - Enlace al repositorio de GitHub
   - Enlace a GitHub Pages (si lo activaste)

## ✨ Ideas Extras (Opcional)

Si quieres destacar, puedes agregar:

- 🖼️ Una foto profesional
- 🔗 Links a tus redes sociales (LinkedIn, GitHub)
- 📊 Barras de progreso para tus habilidades
- 🎨 Animaciones CSS sencillas
- 📱 Diseño responsivo para móviles
- 🌙 Modo oscuro/claro
- 📥 Botón para descargar el CV en PDF

## 🔍 Criterios de Evaluación

Tu proyecto será evaluado según:

| Criterio | Puntos |
